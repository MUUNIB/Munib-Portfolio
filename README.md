# Munib Khan Jadoon: Portfolio

## Run it locally (VS Code)
1. Unzip this folder and open it in VS Code (File > Open Folder).
2. Install the "Live Server" extension, then right-click `index.html` > "Open with Live Server".
   (Or just double-click `index.html` to open it in your browser.)

## Before publishing
- Add your CV as `Munib_khan_CV.pdf` in this folder (the Download CV button uses it).

## Publish on Vercel
Replace `index.html` in the GitHub repo `MUUNIB/Munib-Portfolio`, commit and push. Vercel redeploys automatically.
